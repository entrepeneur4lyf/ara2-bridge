# 0.2.0-alpha.1 Conformance Contract

This tracked document defines candidate inputs; run-specific conclusions live
only in the attested `ara2-evidence-<commit>.tar.zst` artifact. A release is valid
only when its receipt binds the archive digest, repository, GitHub Actions issuer,
release workflow identity, and all 40 successful matrix fragments to one immutable
candidate SHA.

Required gates are formatting, Clippy, stable/MSRV tests, warning-free rustdoc,
generation/provenance/coverage freshness, Rust scenarios, Miri, ASan/UBSan/TSan,
all fuzz targets, C++ pairings, CLAP/VST3/Audio Unit native jobs, dependency and
license audits, seven clean-room packages, and deterministic source-bundle
verification. Commands and runner ownership are normative in
`docs/conformance/ci-matrix.md`.

Before committing candidate bytes, run:

```text
cargo xtask release audit-api
cargo xtask release audit-unsafe
cargo xtask release audit-licenses
cargo xtask release verify-source-inputs --version 0.2.0-alpha.1
```

From the clean candidate commit, `source-bundle` creates the versioned archive and
`verify-source-bundle` regenerates its clean-room lockfile and builds all seven
members offline with a new empty Cargo home. `import-evidence` invokes
`gh attestation verify` internally; `verify` then requires the matching receipt,
40 unique successful same-SHA fragments, the embedded source archive and digest,
and another offline source verification.

The bridge supports the redistributable ARA 2.3 public surface. The separately
licensed AAX API and Audio Unit v3 companion behavior are not claimed.
